# Voice Finance Free v0.4

Повністю безплатний тестовий веб-застосунок без платних AI API.

## Голос
- Мікрофон записується через `MediaRecorder`.
- Аудіо декодується локально у браузері та приводиться до mono 16 kHz.
- Транскрипція працює локально через open-source Whisper у `whisper-worker.js` / Transformers.js.
- На iPhone/iPad використовується multilingual Whisper Tiny q8 через однопотоковий WASM. Це свідомий стабільний режим: `whisper-base` має підтверджені падіння вкладки iOS Safari.
- На сумісних desktop-браузерах спочатку пробується Whisper Base q4 через WebGPU, потім Tiny q8 / WASM.
- Мову жорстко не фіксує: розраховано на українську + польську + англійську в одній фразі.
- Перший запуск завантажує модель з Hugging Face. Це безкоштовно; далі браузер використовує кеш.
- Аудіо не відправляється в OpenAI або інший платний API.
- Запис автоматично зупиняється через 30 секунд, а зависла транскрипція скидається через 4 хвилини.
- Закриття voice sheet або помилка завжди зупиняє всі microphone tracks; застарілі async-відповіді ігноруються.

### Реальне обмеження iPhone

Повністю локальна модель на iPhone має нижчу точність і більшу затримку, ніж хмарний STT. Tiny обрано як найсильніший практичний безкоштовний fallback, який не ставить під ризик перезавантаження всієї вкладки. Текстовий парсер і ручне додавання не залежать від моделі та працюють навіть коли модель не завантажилася.

Перший запуск потребує мережі для завантаження open-source моделі. Safari кешує модель для наступних запусків, але може видалити кеш при нестачі місця.

## Парсер
Локально розбирає суму, валюту, тип операції, клієнта, категорію і відомих мерчантів. Є fuzzy-розпізнавання для варіантів на кшталт `Biedronka / бєдронка / бедронка`.

Перевірені текстові приклади:
- `200 злотих Biedronka` -> Витрата / 200 PLN / Продукти
- `мінус 45 злотих Uber` -> Витрата / 45 PLN / Транспорт
- `плюс 3000 злотих від Johnny за зйомку` -> Дохід / 3000 PLN / Johnny / Бізнес
- `Johnny заплатив мені 2000 за монтаж` -> Дохід / 2000 PLN / Johnny / Бізнес
- `50 євро hotel Booking` -> Витрата / 50 EUR / Подорожі
- `dwieście złotych Biedronka` -> Витрата / 200 PLN / Продукти
- `two hundred PLN Uber` -> Витрата / 200 PLN / Транспорт

## Хостинг
Це повністю статичний сайт. Його можна безкоштовно розмістити на GitHub Pages або іншому безкоштовному статичному HTTPS-хостингу.

GitHub Actions workflow у `.github/workflows/pages.yml` публікує `main` у GitHub Pages без build-кроку та без платних сервісів.
